Name: textseg
Kind: library
Language: plain text
Summary: Example textseg frame and chunk spec for the dev-only build-from-text tool.

Behavior:
- Start each frame with an 8-byte little-endian header
- Cap each frame at 150 bytes
- Apply the per-language rules for the language named in the input

Constraints:
- no network
- no telemetry

Inputs:
- text: string, required
- language: string, required

Outputs:
- frames: array, required

Notes:
- The header matches voiceboi-chunk: message id (uint16), sentence index, chunk index, chunks in the sentence, flags, and CRC-16/CCITT-FALSE over the payload.
- Flag 0x01 marks the last sentence. Flag 0x04 is control. Text chunks do not set it, and a decoder rejects it.
- The two bytes that used to widen the message id sit at the start of the first frame's payload. Sequence and message-wide length are derived from the sentence and chunk fields.
- Cuts stay on UTF-8 and grapheme boundaries.
- Per-language rules choose how text is split into chunks. They do not change the 150-byte cap.
- This file is an example input. It is not a shipmblang runtime format.

Tests:
- a frame longer than 150 bytes is rejected, except one grapheme that cannot be split
- each frame header is 8 bytes
