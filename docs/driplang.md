# DripLang Has Moved To ShipLang

DripLang is now ShipLang, the portable programming layer for ShipMB.

Use the new import path:

```python
from shiplang import printurf
```

The old import path still works as a compatibility shim:

```python
from driplang import printurf
```

Read the current docs in [`shiplang.md`](shiplang.md).
