ShipMBLang

ShipMBLang is the natural language programming layer for ShipMB. Write a program end to end in natural language syntax, compile it to ShipMBLangCore, emit ShipMBLang bytecode, and run the supported instructions locally. 

natural language syntax -> ShipMBLangCore -> ShipMBLang bytecode -> runtime/machine execution
